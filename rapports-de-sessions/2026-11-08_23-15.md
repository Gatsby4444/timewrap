### Bug : l'en-tête Jour / Semaine ne correspondait pas à la grille
Cause, trouvée dans le code (`ui/DayWeekScreens.kt`) — deux sources de vérité :
1. Le bouton « Aujourd'hui » / « Cette semaine » changeait la date retenue (donc l'en-tête) **sans
   faire tourner le pager** : la grille restait sur l'ancienne page.
2. La page centrale du pager valait « aujourd'hui », recalculé à chaque affichage. Le lendemain
   (minuit, ou appli rouverte), la même page désignait un autre jour : décalage d'un jour.
   Le collecteur des glissements gardait en plus l'ancien « aujourd'hui » capturé au départ.
3. Même défaut pour tout changement venu d'ailleurs : import, événement enregistré, onglet À faire.

Correction par la cause : origine fixe (lundi 3 janvier 2000 = page 0) — une page désigne toujours
le même jour ; la date du modèle est la seule vérité et le pager la suit (`SyncPager`) ;
l'en-tête affiche la page réellement montrée ; « aujourd'hui » vient du modèle (`state.today`,
calculé par le cœur), plus de `todayEpochDay()` dans les écrans Jour / Semaine / grille.

Défauts voisins réparés dans la foulée :
- Le rafraîchissement toutes les 30 s **vidait tout le cache** : la grille clignotait sur
  « Chargement… ». Remplacé par `tick()` : il ne relit les journées que si le jour a tourné ou si
  une synchronisation est passée, et les remplace d'un bloc.
- Ce battement tournait même appli en arrière-plan : il ne tourne plus que quand l'appli est
  à l'écran (`repeatOnLifecycle(STARTED)`), et le premier battement au retour détecte le
  changement de jour (qui regardait « aujourd'hui » passe au nouveau jour).
- Le cache tenait des bornes à part (`loadedFrom` / `loadedTo`) qui, après un saut lointain,
  faisaient lire tous les mois intermédiaires : supprimées, le cache sait ce qu'il contient.

## Difficultés rencontrées

- Les scripts Python passés en heredoc par l'outil Bash perdent parfois les `\r\n` littéraux et
  les guillemets triples : les chaînes `"\r\n"` des tests sont devenues de vrais retours à la
  ligne. **Éviter** : écrire le script dans un fichier du dossier temporaire, ou utiliser Edit.
- Écrire un fichier en mode texte Python sous Windows le convertit en CRLF. **Éviter** :
  `open(..., newline="")` en lecture comme en écriture. Plusieurs fichiers Kotlin du dépôt
  étaient déjà en CRLF dans la copie de travail (le dépôt, lui, est en LF) : normalisés.
- `./gradlew assembleDebug` dépasse 10 minutes à froid (trois ABI Rust) : le lancer en arrière-plan.
